    How it works

    1. Register. The genesis block lists the election, the candidates and the IDs of the registered voters.
    2. Sign. A vote is signed with the voter's private key (ECDSA P-256). Anyone can check it with their public key, but nobody can forge or change it without the private key.
    3. Mine. Pending votes go into a block with a Merkle root of their hashes. The miner tries nonces until the block's SHA-256 hash starts with enough zeros (proof of work).
    4. Link. Each block stores the hash of the one before it, so editing an old block breaks every link after it.
    5. Check. Before counting, every block is re-verified: hashes, links, proof of work, signatures, registered voters and one vote per voter.

    This demo runs one node in your browser so you can see each step. The full project usually adds a Solidity smart contract on an Ethereum test network, wallet sign-in with MetaMask, an admin panel to register voters and open or close the election, and the report and diagrams.
